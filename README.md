# Последний жар

3D-стратегия о выживании города вокруг генератора в ледяном мире (React + three.js).

## Запуск

1. Установите Node.js 20 или новее: https://nodejs.org
2. Откройте терминал в этой папке и выполните:

```bash
npm install
npm run dev
```

3. Откройте адрес, который появится в консоли (обычно http://localhost:5173).

## Сборка

```bash
npm run build     # готовая игра в папке dist/
npm run preview   # проверить сборку локально
```

## Возможности

- Интерфейс в стиле Frostpunk: термометр и ресурсы сверху, задания слева, панель объекта справа, надежда и недовольство снизу.
- Угольные и рудные шахты на месте куч, лимиты складов, угольный склад и склад ресурсов.
- Кладбище, бойцовская арена и паб (открываются законами); непогребённые тела злят людей.
- Задания сценария в 4 этапа.
- Сохранения: 3 слота и автосохранение каждое утро (в localStorage браузера).
- Горожане строят, копают, носят грузы, охотятся, общаются и греются у генератора.
- Детализированные процедурные 3D-модели и текстуры.
- 1 игровой час = 8 секунд на обычной скорости.

## Управление

- ЛКМ — выбор, перетаскивание ЛКМ — поворот камеры
- ПКМ / WASD — сдвиг камеры, колесо — масштаб
- Shift — строить несколько зданий подряд, Esc / ПКМ — отмена

Шрифты загружаются из Google Fonts; без интернета игра работает со стандартными шрифтами.
