# Последний жар

3D-стратегия о выживании города вокруг генератора в ледяном мире (React + three.js).

## Запуск

1. Установите Node.js 20 или новее: https://nodejs.org
2. Откройте терминал в этой папке и выполните:

```bash
npm install
npm run dev
```

3. Откройте адрес, который появится в консоли (обычно http://localhost:5173).

## Сборка

```bash
npm run build     # готовая игра в папке dist/
npm run preview   # проверить сборку локально
```

Папку `dist/` можно выложить на любой статический хостинг.
Открывать `dist/index.html` двойным щелчком не стоит — браузер заблокирует модули, используйте `npm run preview`.

## Управление

- ЛКМ — выбор, перетаскивание ЛКМ — поворот камеры
- ПКМ / WASD — сдвиг камеры, колесо — масштаб
- Shift — строить несколько зданий подряд, Esc / ПКМ — отмена

Шрифты загружаются из Google Fonts; без интернета игра работает со стандартными шрифтами.
